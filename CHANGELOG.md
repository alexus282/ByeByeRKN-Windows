# Changelog

## 0.1.0 — first Windows alpha

Первый публичный релиз Windows-порта.

- Регистрация WARP-устройства, WARP+ и split ClientHello.
- Поиск эндпоинтов real handshake-пробами, автоподбор маскировки.
- Wintun-адаптер: адреса, MTU, DNS, маршруты и корректный откат.
- Проверка, что трафик действительно идёт через WARP; MTU fallback 1280 → 1200 → 1100.
- Монитор зависаний и автоматическое переподключение.
- Окно в стиле Android-приложения: главная, настройки, журнал, трей.
- Служба Windows: после установки окно не требует прав администратора.
- Установщик с выбором папки, ярлыков, автозапуска и запуска после установки.
- Portable-режим без службы.
- Копирование и сохранение wg-quick-конфига.

Известные ограничения: нет MASQUE и раздельного туннелирования, exe не подписан,
используется `amneziawg-go` v1.0.4 (апгрейд на v3.1 запланирован).
